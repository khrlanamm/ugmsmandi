# UGM at Expo Campus Smandi 2025

Booth page for Universitas Gadjah Mada at Expo Campus Smandi 2025, the campus expo at SMA Negeri 1 Sukodadi. Visitors scanned a QR code at the booth to open it.

The page collects admission material in one place: the registration brochure, undergraduate (S1) and applied bachelor (D4) programs, program quotas, admission competitiveness, accreditation, and tuition (UKT) for the SNBP and SNBT routes.

Plain HTML, CSS, and a few lines of JavaScript for the tab menu (`js/main.js`). Open `index.html` in a browser to view it.

The expo is over, so this repository is archived.
